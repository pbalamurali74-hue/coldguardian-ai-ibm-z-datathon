# Demo data

All CSVs in this directory are **synthetic demonstration records** prepared to reproduce the sample scenario discussed by Dataset Distractors.

They are not live telemetry, not a public benchmark, and not suitable for medical or operational decisions. The sample includes three shipments, three facilities, and 12 sensor readings for SH001. SH002 and SH003 are deliberately flagged for missing sensor readings in the quality report. SH003's reported current temperature conflicts with that missing-reading flag; the demo is intended to show reconciliation behavior.

Replace these illustrative records with an approved, representative dataset before evaluating the system beyond a software demonstration.
