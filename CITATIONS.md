# Open-source resources and dependencies

This repository uses these open-source libraries:
- Python — https://www.python.org/
- pandas — https://pandas.pydata.org/
- NumPy — https://numpy.org/
- Matplotlib — https://matplotlib.org/
- JupyterLab — https://jupyter.org/
- ipywidgets — https://ipywidgets.readthedocs.io/

The command-line module in this repository directly imports pandas and NumPy. Matplotlib and ipywidgets are used by the team's notebook workflow. Keep this list updated if the final submitted code uses additional libraries, models, datasets, or APIs.

The bundled CSV examples are synthetic and created for this demonstration. They are not external medical datasets.
